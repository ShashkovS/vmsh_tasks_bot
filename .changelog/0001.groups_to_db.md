# Проект: перенос групп (levels) из хардкода в БД и Google Sheets

## Зачем это нужно

Сейчас группы (уровни) захардкожены в коде и размазаны по нескольким слоям: константы, обработчики команд,
формирование клавиатур, тексты сообщений, отчёты, веб-статистика и SQL-запросы. Это ограничивает масштаб:
невозможно гибко завести десятки предметных групп, менять названия/команды без деплоя, хранить разные настройки
для разных параллелей, а также корректно ограничивать доступ учителей и школьников к «чужим» задачам.

Цель проекта — сделать группы конфигурируемыми через Google Sheets и хранить их в БД, чтобы можно было
«пересадить» в бота целую школу: у ученика могут быть несколько предметов/групп, он может переключаться
только между разрешёнными, а учитель видит (и может модерать) только «свои» группы, задачи, вопросы,
сдачи и отчёты.

## Что хотим изменить (поведенчески, без деталей реализации)

- Убрать статические `LEVEL_*`/`LEVEL` и перейти на таблицу групп.
- Ввести список доступных групп у пользователя (через `;`), с ограничением всех сценариев:
  показ задач/уроков, выбор задач на проверку, вопросы SOS, постановка плюсов, отчёты, игровые механики.
- Свести все отображения/команды/ссылки к данным группы (а не к enum-ам и словарям в коде).

## Поля группы (полный список, который нужен для текущего функционала и масштабирования)

Обязательные:

- `group_id`: уникальный текстовый id группы (без `;`), стабильный ключ в БД и таблицах.
- `broadcast`: broadcast id --- уникальный текстовый id для проведения рассылок. [a-z0-9-]+ 
- `short_code`: короткое обозначение для номера задач/уроков и кратких списков (может совпадать у разных групп).
- `broadcast_code`: код для упоминания группы в broadcast-рассылках (уникальная, например `all_novice`).
- `tg_command`: телеграм-команда переключения (уникальная, например `/level_novice`).
- `public_name`: публичное название для сообщений и кнопок (аналог `level.slevel`).
- `conditions_url`: ссылка на условия/страницу группы (аналог `level.url`, используется в шапке задач).
- `tasks_header_template`: текст шапки списка задач (HTML), с плейсхолдерами для `{student}`, `{mode_hint}`, `{group.public_name}`, `{group.conditions_url}` и
  др.

Рекомендуемые/служебные (нужны для полного покрытия текущих сценариев):

- `switch_message`: текст, который получает школьник при смене группы (сейчас `you_are_in_*`).
- `sort_order`: порядок отображения групп в UI (кнопки смены уровня, списки).
- `is_active`: включена ли группа в текущем семестре (не показывать и не принимать сдачи) (default true)
- `is_default`: группа по умолчанию для новых/неполных записей.
- `allow_self_switch`: может ли школьник сам переходить по команде.
- `is_system`: служебная группа вроде «без уровня», скрытая от обычных списков (default false)
- `score_weight` или `score_weight`: ранжирование сложности для игровых/статистических правил (сейчас логика в `apps/game_web_app.py` захардкожена под н/п/э). (
  default 1.0)

# Phase 8: уведомления об ответах преподавателя

## Проверяемый результат

- Ответ преподавателя или администратора в приватном обсуждении создаёт для
  активного Student-аккаунта событие `thread_updated`.
- Событие ведёт в исходный тред и содержит только публичные идентификаторы треда
  и записи.
- Повтор HTTP-команды с тем же idempotency key не создаёт второе уведомление:
  dedupe key равен `public_id` сохранённой записи.
- Сообщение самого школьника не создаёт уведомление для него самого.
- Только Student-инвалидация получает ресурс `notification-events`; Staff
  продолжает обновлять очередь и тред без персонального события.

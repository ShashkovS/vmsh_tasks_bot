## Настройки задач, студентов и учителей в гугл-таблице

### Группы
Лист `Группы` используется как источник истины по учебным группам. Колонки:
- `group_id` — уникальный текстовый id, символ `;` запрещён
- `short_code` — короткая метка для вывода в списках задач (не обязательно уникальная)
- `broadcast_code` — токен для `/broadcast` (например `all_novice`)
- `tg_command` — команда для перехода в группу (например `/group_novice`)
- `public_name` — публичное имя группы для сообщений и кнопок
- `conditions_url` — ссылка на условия/страницу группы
- `tasks_header_template` — шаблон шапки списка задач
- `switch_message` — текст для ответа ученику при смене группы
- `sort_order` — порядок сортировки групп в интерфейсах
- `is_active` — активность (0/1)
- `is_default` — является ли группой по умолчанию (0/1)
- `allow_self_switch` — разрешена ли самосмена через `tg_command` (0/1)
- `is_system` — системная группа (0/1)
- `score_weight` — коэффициент пересчёта игровых очков

### Студенты и учителя
Листы `Школьники` и `Учителя` принимают дополнительные колонки:
- `group_id` — текущая группа пользователя
- `allowed_groups` — список доступных групп в формате `;group_id;group_id;` (пустое значение = нет ограничений).

# Weekly Lifecycle Map

This folder captures the weekly lifecycle of the circle as it exists now, before migration from Telegram bot to web.

The map combines:
- public-facing rules from the circle announcements;
- actual product behavior from code;
- observed trace patterns from March 2026.

Important assumptions:
- the canonical weekly unit is one lesson `N`;
- Monday starts the new lesson;
- oral acceptance is concentrated in fixed time windows;
- outside oral windows, work happens mostly through bot-driven written/test submission and asynchronous teacher review;
- legacy waitlist code is not treated as an active lifecycle stage.

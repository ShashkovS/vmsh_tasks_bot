# Названия задач во всех списках — 11 сентября 2026

В Student и Family каждый заголовок листка показывает номер и название задачи.
Название берётся из проверенных метаданных соответствующей версии условия;
при отсутствии метаданных сохраняется название исходника, а при отсутствии
обоих — только номер. У самостоятельных пунктов видны собственные названия.
Для подсказок и решений сопоставление идёт по ID задачи с опубликованным
условием, а не по совпадению номеров. Данные ответов и checker в документ не попадают.
Хранимые производные не меняются, перекомпиляция и миграция не нужны.

Реализация: `db_methods/pwa/content.py` (`_overlay_problem_titles`,
`get_published_content`, `apply_problem_titles`, reveal),
`apps/pwa_api/content_routes.py` (Staff preview),
`packages/contracts/src/content.ts` (необязательное название пункта),
`packages/content/src/math-document.tsx` и `content.css` (общий рендер).

В Staff названия постоянно видны в очной таблице, компактной Zoom-сетке,
сводке и подробной истории результатов школьника. Номера и действия сохраняются;
длинные названия переносятся. Таблицы прокручиваются внутри своей области.
Реализация: `apps/staff/src/live-marking-grid.tsx`, `student-results-page.tsx`.
Очередь проверки, статистика задач, сопоставление, TaskListItem уже показывают названия.

Проверка: backend — опубликованная версия против черновика, fallback,
отдельные пункты, Student/Family/Staff и reveal. UI — типизированный рендер,
мобильный листок, тёмная тема, длинные названия, таблицы Staff.
Результаты проверки фиксируются в обоих STATUS.md и отчёте.

# Восстановление отклонённой замены письменного решения

Замена доступна только для awaiting_review и незаблокированных материалов. Серверные запреты сохраняются. При 409 written_replacement_unavailable, written_replacement_target_changed или written_attachment_locked интерфейс предлагает явно отправить сохранённое исправление новым сообщением. Автоматической отправки нет.

`apps/student/src/student-written-chat.ts` ограничивает действие; `student-written-submission.tsx` показывает восстановление вместо редактирования застрявшей операции. `packages/offline/src/written-submission-outbox.ts` атомарно переводит отклонённый снимок в обычную отправку с новыми ключами идемпотентности и новым серверным черновиком. Локальные фотографии и текст сохраняются до подтверждения; повторные нажатия используют одну операцию. Поддерживается восстановление после перезагрузки, без миграций.

Проверки: `student-written-chat.test.ts`, `written-submission-outbox.test.ts` (проверенная работа, заблокированные фото, сохранённый конфликт, фото, конкурентные повторы).

# Проверка письменных работ простынёй

Решение владельца, 11 октября 2026. Реализовано на свежей основе `7dd8c5a5`.
Функциональные проверки простыни прошли; полный release gate имеет ограничения,
перечисленные в [отчёте](../../pwa_tests/reports/review-sheet-20261011/README.md).

Teacher/Admin открывают занятие или целый номер задачи со всеми пунктами.
По умолчанию показываются ожидающие работы, переключатель «Все» добавляет
проверенные диалоги нового формата. Старые Telegram-only диалоги исключены.
До 300 уникальных карточек включительно разрешена простыня занятия;
свыше 300 — только по задаче. Счётчик зависит от выбранного режима.

Задачи и пункты идут в порядке каталога. Перед номером раскрыто условие всех
пунктов, далее работы по А, Б, В. Внутри пункта — старые работы первыми.
Синонимы сохраняют одну общую проверку и не размножают формы.

Простыня не создаёт leases. Чужой захват не запрещает запись. Сервер в одной
write-транзакции проверяет snapshot результата, материалов и связанных веток.
При конфликте обновляется только карточка, сохраняется черновик; преподаватель
может отправить новый результат либо отказаться. Новый результат append-only,
предыдущие проверки сохраняются. Повтор HTTP-запроса идемпотентен.

Для оценки берутся непроверенные материалы, иначе evidence последней проверки.
Полная переписка не расширяет evidence. Доступ ограничен текущими Staff grants,
включая все связанные ветки. Обычная история и её ограничения не меняются.

Реализация: [домен](../../models/pwa/review_sheet.py),
[SQLite](../../db_methods/pwa/review_sheet.py),
[API](../../apps/pwa_api/review_routes.py),
[страница](../apps/staff/src/review-sheet-page.tsx),
[карточка](../apps/staff/src/review-sheet-card.tsx) и
[контракты](../packages/contracts/src/review-sheet.ts). Общие формы и фотографии используют
актуальные компоненты из [просмотра фотографий](review-photo-preview.md).

При проверке нужны две независимые сессии, одиночная проверка параллельно
простыне, обе роли, границы 299/300/301, multipart/synonyms, аннотации,
сохранность черновиков и Student/Family-проекции. Итоговый gate:
`make pwa-check-release` на изолированном runtime.

Состав открытой простыни сохраняется до явного обновления или смены фильтра.
Фоновые события очереди не удаляют карточки и не продвигают snapshot формы;
после CAS-конфликта меняется только нужный диалог.

Проверено: 2981 Python / 12 SKIP, 1101 frontend, 375 Storybook; сценарии
простыни и других режимов проверки PASS во всех трёх браузерах, light/dark и
390 px. Общий E2E: 399 PASS / 20 SKIP / 4 FAIL вне простыни; дополнительный
прогон на чистых фазах — 48 + 12 + 9 PASS, Staff visual 3 PASS. Остаются
нестабильный offline problem-release и три старых Student visual baselines.
[Квитанции и снимки](../../pwa_tests/reports/review-sheet-20261011/README.md).

Выпущено `08d4926d` на оба production с разрешения владельца после сообщения
об ограничениях gate: по 25 HTTP checks и 116 Staff hashes PASS.

## 11 октября — единая переписка без повторов

По замечанию владельца сообщения показываются один раз в общем диалоге.
Отдельный блок «Материалы оценки» убран. Перенос/клонирование и редактирование
фотографий находятся в самом сообщении текущей работы. Архивные сообщения и
результаты остаются в хронологическом порядке. Evidence/CAS и права не меняются.
`entryId` в [sheet conversation](../packages/contracts/src/review-sheet.ts) связывает
архивное событие с [ReviewEvidenceEntry](../apps/staff/src/review-workspace-page.tsx).
Пока страницы переписки загружаются, текущая работа уже доступна; после загрузки
то же сообщение сохраняет свою форму и редактор.

Исправление реализовано, fast gate PASS: 2981 Python / 12 SKIP, 1102 frontend,
375 Storybook и 10 Chromium E2E. [Проверки](../../pwa_tests/reports/review-sheet-conversation-20261011/README.md).
Исправление `9e98e282` выпущено на оба production: по 25 HTTP checks и 116 Staff hashes PASS; службы active, maintenance off.

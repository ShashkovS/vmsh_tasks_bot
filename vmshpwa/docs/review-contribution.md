# Личный вклад учителя

Решение владельца от 17 ноября 2026: компактный «Ваш вклад» в очереди,
письменной проверке, простыне, очном и Zoom-приёме. Подробности раскрываются
по нажатию, не отодвигают рабочую область на мобильном по умолчанию.

## Подсчёт

Только собственные человеческие проверки через PWA, включая историю PWA:
`submission_reviews.source=staff`, `live_mark_results` и результаты устных
приёмов с `zoom_conversation.pwa_idempotency_key`. Пересечение устных
источников учитывается один раз. Telegram, AI, автоматические тесты,
«не сдавал» и тестовые ученики исключены. Новая письменная попытка даёт новую
проверку; correction меняет её оценку, сохраняя первоначального автора,
занятие и дату. Плюсы: `verdicts.val >= 0.8` (включая `+.`).

По уточнению владельца отмены и переключения устных оценок специально не
сворачиваются и не вычитаются. Нового журнала достижений/попыток нет.
Повторы запросов используют существующую идемпотентность сохранения.

Общий итог — собственная история этого портала, включая архивные курсы.
Выбор курса/занятия ограничен текущими Staff grants и опубликованными
занятиями. Фильтр группы очереди не ограничивает вклад в выбранное занятие.
При одном курсе он выбирается автоматически; при нескольких курсах без
выбора показывается общий итог и выбор курса в подробностях.

День определяется по первоначальному сохранению проверки, не номеру занятия.
Календарь серий: Europe/Moscow, неделя понедельник–воскресенье. Минимум три
проверки за день/неделю. Незавершённый текущий период не обрывает серию,
закончившуюся в предыдущем периоде. Личный рекорд сохраняется после перерыва.

## Рубежи и тексты

За занятие: 1, 10, 25, 50, 100, 200, 500, 1000, затем каждые 1000.
За всё время: 1, 10, 50, 100, 250, 500, 1000, 2500, 5000, 10000,
затем каждые 5000. Дни: 2, 3, 5, 7, 14, 30, затем каждые 30.
Недели: 2, 4, 8, 12, 26, 52, затем каждые 26.

Основание — read-only production-снимок 7 сентября–3 октября 2026:
14755 PWA проверок у 38 учителей, 91 сочетание учитель/курс/занятие.
Медиана за занятие 39, p75=112; 10 достигли 77 сочетаний, 50 — 40,
100 — 27. Медиана дневного рекорда с порогом 3 проверки — 2 дня,
максимум 17. Это историческая выборка первого месяца работы, не live-итог.

Показываем ближайшую шкалу и достигнутые отметки. «Первая проверка за
занятие. Спасибо, что помогаете ребятам разобраться»; «10 проверок за
занятие. Спасибо за ваш вклад»; далее числовые рубежи. Плюсы справочные,
достижения зависят от общего объёма. Нет рейтинга, конфетти и напоминаний
о потере серии. Старые достижения при загрузке не поздравляют повторно.

## Реализация и приёмка

Read model: `db_methods/pwa/review_contribution.py`, расчёт:
`models/pwa/review_contribution.py`, GET
`/staff/api/v1/review/my-contribution` в `apps/pwa_api/review_routes.py`.
Контракт/client: `packages/{contracts,app-shell}/src/review-contribution.ts`.
UI: `apps/staff/src/review-contribution.tsx`; потребители — очередь,
workspace, sheet, live marking и старый PWA oral form.

При загрузке/ошибке нет вымышленных нулей. После первой сохранённой проверки
блок появляется; обновления не блокируют ввод/следующую работу и не двигают
фокус. Показатели обновляются при подтверждённом сохранении и возврате к
странице. Сервер не принимает teacher ID из браузера.

Проверки: domain/HTTP подсчёт и права, contract/client, компонентные stories,
E2E review/oral/live-marking, 320/390/1440 px, обе темы, клавиатура,
200% zoom, reduced motion. Схема и production данные не меняются.

### Проверка и оставшиеся ограничения

Реализация завершена: 8 server, 8 focused frontend, 7 focused Storybook и
15 Chromium E2E PASS; types/lint/i18n/builds PASS. Все семь снимков двух тем,
320/390/1440 px и CSS zoom 200% просмотрены. Смена фильтров сохраняет native
раскрытие и фокус через TanStack Query `keepPreviousData`; предыдущий контекст
подписан, пока загружаются новые показатели. Шкалы используют общий `Progress`.

Полный gate ограничен 12 прежними format failures и двумя прежними Python
failures. У простыни на 320 px сохранилось переполнение на 18 px, новый блок
его не увеличивает и сам помещается. [Доказательства и снимки](../../pwa_tests/reports/review-contribution-20261117/README.md).
Production не менялся.

Read-only замер существующего production-снимка: собственные 5755 проверок,
около 0.22 секунды на SQLite projection после оптимизации join corrections.
Новый API не использует analytics snapshots и не меняет учебные результаты.
Дополнительный query `groupLesson` разрешает контекст простыни/устного приёма
через тот же ограниченный каталог опубликованных занятий; его нельзя смешивать
с `course`/`lesson`.

# Результаты школьника — принятое задание, 10 сентября 2026

Админский read-only `/staff/student-results`: fuzzy-поиск, сводка плюсов за
занятия с активностью, выбранное любое занятие с посылками всех уровней.
Включены PWA и сохранённая Telegram-история, прошлые вердикты, внутренние
пометки, фотографии и аннотации. Форм сдачи/редактирования здесь нет;
современные проверки открываются существующими маршрутами.

Сводка использует effective_results; архивные группы, занятия и ученики без
PWA-аккаунта доступны. Устные оценки без посылок остаются в таблице и имеют
просмотр истории. SOS и несданные черновики исключены. Связи result_id и
legacy_discussion_id исключают двойной показ; переносы и клоны сохраняются.
Старые файлы читаются только из solutions через авторизованный endpoint по ID,
пути с токенами не выдаются. Отсутствующие файлы/условия не скрывают историю.

## Устройство экрана и URL

`student`, `course`, `lesson` хранятся в валидируемых параметрах маршрута.
При выборе школьника по умолчанию открывается максимальный номер занятия с
активностью; если активности нет — последнее доступное занятие курса.
Обзор содержит только занятия с активностью, селектор — весь каталог, включая
старые номера из `problems`. Таблицы группируются по уровням, сортируются в
порядке курса и показывают исходные символы оценок. Нажатие на оценку открывает
read-only ленту, на занятие — выбирает и прокручивает подробности.

Подробности включают только отправленные материалы или попытки теста. История
хронологическая, по 50 событий с продолжением по стабильному ID последнего
события. Текущий результат отделён от предыдущих проверок. Непроверенные попытки,
замены, переносы целых посылок/частей материалов, клоны, исправления и undo
сохраняют свои события. Zoom-пометки отделены от задач; изменения и отмены
восстанавливаются из `live_mark_operations`, когда такой журнал существует.

Условие при отправке читается по связанному `problem_revision_id`. При отсутствии
современного документа показывается сохранённый `prob_text` с подписью «версия
неизвестна», либо сообщение о недоступности. Отсутствующий/несовместимый документ
не скрывает посылки. Тексты старых `.txt` читаются как текст; фотографии загружаются
рядом с экраном, другие вложения доступны для скачивания. История использует
`ThreadMessage`, `VerdictMark`, `ReviewAnnotationViewer`, `SemanticMathDocument`.

[Страница](../apps/staff/src/student-results-page.tsx) использует TanStack Query:
отдельные запросы справочника, сводки и занятия, обновление при возвращении и
по кнопке. При потере сети остаются уже загруженные данные и явный статус;
запросы возобновляются после подключения. Автоматическое заполнение параметров
[истории проверки](../apps/staff/src/review-history-page.tsx) использует replace,
чтобы браузерный Back возвращал к школьнику, а не к промежуточному URL проверки.

## API и границы доступа

Все маршруты ниже — GET под `/staff/api/v1/student-results`. Каждый запрос,
включая фотографии и условия, проверяет Staff-сессию и админское право
`audit.read`. Создание/подмена ученической сессии не используется.

| Путь                                                 | Ответ                                                              |
| ---------------------------------------------------- | ------------------------------------------------------------------ |
| `/directory`                                         | Школьники, включая архивных без PWA-аккаунта                       |
| `/{student}/overview?course=…`                       | Курсы, каталог занятий, сводные таблицы                            |
| `/{student}/lessons/{course}/{number}`               | Отправленные задачи по уровням, первые страницы лент, Zoom-пометки |
| `/{student}/problems/{problem}/history?cursor=…`     | Следующие 50 событий                                               |
| `/{student}/problems/{problem}/condition/{revision}` | Связанная версия условия                                           |
| `/{student}/attachments/{attachment}`                | Защищённое PWA-вложение с проверкой целостности                    |
| `/{student}/legacy-attachments/{discussion}`         | Сохранённое вложение Telegram по ID обсуждения                     |

Файлы Telegram ограничены каталогом `solutions`; абсолютные префиксы прежних
развёртываний переводятся на тот же корень, выход за него и симлинки наружу
отклоняются. Имена каталогов/файлов с токенами не сериализуются. HTML/SVG и
неизвестные форматы не выдаются как активная страница. В agent/E2E используется
только `<media-root>/legacy-solutions`; интеграционные тесты задают временный
корень. Telegram/Google при чтении не вызываются. Новых миграций и изменений
существующих записей нет.

Полнота означает все **сохранившиеся** записи. Утраченные файлы, неизвестную
версию старого условия и значения, перезаписанные без журнала, восстановить
нельзя. Отдельные вопросы/SOS сюда не входят.

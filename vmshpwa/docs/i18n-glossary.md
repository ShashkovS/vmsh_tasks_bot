# Глоссарий перевода интерфейса

Единые английские термины для каталогов `.po` ([docs/i18n.md](i18n.md)). Стиль: нейтральное «you» вместо «вы», короткие глаголы в кнопках (Save, Retry), sentence case в заголовках («Active group», не «Active Group»). Русский исходник не содержит рекламной и соревновательной лексики — английский тоже.

Строки, помеченные «владелец», ждут решения владельца продукта; до решения используется предложенный вариант.

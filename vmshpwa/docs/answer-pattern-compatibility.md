# Совместимость шаблонов ответов с браузерами

Инцидент 16 сентября 2026: в задаче «Музыкальный цикл» шаблоны ноты
`^(?i:до|ре|ми|фа|соль|ля|си)$` и названия пальца используют Python scoped flags.
`answer-validation.ts` пытался создать JS RegExp; при SyntaxError возвращал false,
поэтому несовместимый браузер блокировал любой ответ до отправки на сервер.
Это зависит от версии JS-движка, а не от регистра введённого ответа.

[validateAnswerFormat](../packages/product/src/answer-validation.ts) теперь
пропускает предварительную проверку, когда браузер не может скомпилировать
пользовательский шаблон. Поддерживаемые шаблоны и стандартные числовые форматы
по-прежнему проверяются. Пустой ответ контролируется формой отдельно.
Серверный `models/pwa/submissions.py:evaluate_test_answer` остаётся источником
решения: Python fullmatch, затем проверка правильности. Настройки задач,
правильные ответы и результаты учеников не изменяются.

Регрессии: `answer-validation.test.ts` (включая эмуляцию SyntaxError старого Safari),
`test-answer.stories.tsx:PythonPattern`,
`pwa_tests/domain/test_pwa_test_submissions.py`.

Дополнительно `helpers/checkers.py:str_eq` сначала сравнивает строки без учёта
регистра, затем выполняет прежнюю замену похожих кириллических/латинских букв.
Это сохраняет прежние совпадения и исправляет «МИ» ≠ «ми» из-за несимметричной
таблицы замены. Новые проверки имеют `pwa-test-checker-v2`; старые попытки
и оценки не перепроверяются автоматически.

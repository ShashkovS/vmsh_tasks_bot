# Материалы для разбора в Zoom

Реализовано, 2026-09-13. Staff → «Материалы для разбора»: опубликованные условия
доступных курсов, занятий и уровней. Учителя ограничены назначенными группами.
Одна задача со всеми пунктами — один PNG, 1600 px шириной, высота по содержимому.
Белая бумага, печатная типографика; без ответов, подсказок, решений и управления.
В ZIP по умолчанию включена базовая статистика без персональных данных и сложности.
Имена: `<course>_01э.01.png`, `<course>_01э_статистика.png`, `<course>_01э_разбор.zip`.

Реализация: `apps/pwa_api/whiteboard_export_routes.py`,
`db_methods/pwa/whiteboard_export.py`, Staff `/whiteboard-export`.
Общий renderer и печатные правила; html-to-image и fflate загружаются лениво.
Генерация последовательная, с ожиданием шрифтов/изображений, прогрессом и отменой.
При ошибке задачи ZIP не скачивается; при ошибке статистики её можно явно исключить.
Снимок публикации фиксируется на начало генерации. Миграций и хранения ZIP нет.

Каталог `GET /staff/api/v1/whiteboard-export` содержит только действующие
публикации условий; архивный статус занятия не исключает публикацию.
`GET /staff/api/v1/whiteboard-export/{groupLessonId}?statistics=1` возвращает
снимок документа, ID публикации, названия, авторские масштабы и базовые показатели.
`statistics=0` явно исключает расчёт статистики. Изображения выдаются через
`/{groupLessonId}/assets/{assetId}` после проверки области преподавателя и
принадлежности рисунка выбранной публикации. Произвольные пути не принимаются.

Выбор курса, занятия и уровня хранится в URL. Во время генерации выбор отключён;
показываются прогресс и «Отмена». Отмена и ошибка не скачивают частичный архив.
После ошибки статистики доступны повтор и «Скачать без статистики».
Содержательное введение сохраняется как `<course>_01э_введение.png`;
одни разделители и заголовки введением не считаются.

Область экспорта — 800 CSS px, масштаб ×2, шрифт 11 pt. Каждый PNG ограничен
16 млн пикселей и высотой 16000 px. Ожидание шрифтов и изображений ограничено
30 секундами и прерывается отменой. SVG и растровые рисунки компонуются из
декодированных изображений прямо на canvas: это предотвращает исчезновение
растровых картинок внутри `foreignObject` в WebKit. Общие бумажные стили находятся
в `packages/content/src/worksheet-paper.css`; Student подключает их только для
печати, Staff — только для экспортной области. PNG не содержит разрывов страниц.

Проверки и примеры: [отчёт](whiteboard-export-report.md).

Номер занятия — целое неотрицательное число: занятие `0` («Знакомство»)
доступно в каталоге и экспорте, с префиксом `vmsh_00н`. Контракт и регрессия:
`packages/contracts/src/whiteboard-export.ts`, `whiteboard-export.test.ts`.

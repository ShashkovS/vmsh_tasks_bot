# Схемы и диагностика

`tools/list` возвращает актуальные имена и JSON Schema инструментов.
Для операций Staff identifiers содержит строковые ID из описания инструмента,
body — поля соответствующей операции, etag — строку целиком с кавычками.
Для одной схемы вызовите `get_admin_guide("tools/set_submission_cutoff")` или прочтите ресурс `admin-guide://portal/tools/set_submission_cutoff`.
Пустой identifiers имеет вид `{}`. Схемы отдельных файлов содержат file_id и download_url.
Вложения передаются нативным файловым параметром инструмента.

- 401 — повторите подключение через OAuth.
- 403 — проверьте аккаунт, полномочие Staff и назначение курса либо группы.
- 409 — перечитайте ресурс и покажите пользователю различия перед повтором.
- content_assets_missing — загрузите имена из missingAssets и повторите компиляцию.
- Результат TSV с errors требует исправления указанных строк.
- operation_failed содержит requestId для сверки со Staff-аудитом.

## Длительные операции и повторы

Для компиляции, генерации, перепроверки и других команд из [каталога Staff](../../../admin_mcp/operations.py)
используйте `start_operation(operation, identifiers, body, etag, request_key)`.
Проверяйте `get_operation(operation_id)` до completed или failed. Повторный старт
с тем же ключом и параметрами возвращает тот же operationId. После аварии процесса
состояние interrupted означает, что нужно сверить сохранённую ревизию или историю
результатов. Сервер хранит квитанции в SQLite и проверяет права при каждом чтении.

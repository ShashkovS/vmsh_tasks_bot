# Материалы занятия

1. Найдите группу и занятие либо вызовите `create_lesson` с датой, зоной, окном приёма и новым idempotencyKey. При сетевом повторе сохраните тот же ключ и параметры.
2. Передайте TeX в `upload_material` как source или файл чата. Для условий используйте condition, для подсказок hint, для решений solution. Сохраните revisionId и etag.
3. Прочитайте `material_assets`. Для каждой отсутствующей ссылки вызовите `upload_figure` и используйте новый ETag. Запустите `compile_material`, проверьте `material_diagnostics`.
4. Через `problem_matches` и `save_problem_matches` свяжите строки с задачами. Просмотрите `metadata_grid`. Для серверного черновика используйте `generate_metadata`, просмотрите возвращённые строки и сохраните их через `save_metadata_grid`.
5. `export_metadata_tsv` выдаёт файл с русскими заголовками. Прочитайте его через `read_export(export_id)` или откройте под своим Staff-аккаунтом в течение десяти минут. Загрузите исправленный TSV через `edit_metadata`. Сначала проверьте changes и errors, затем повторите с apply=true и тем же ETag. При конфликте скачайте свежую таблицу.
6. `render_html` принимает ID занятия и mode. Для черновика передайте revisions с идентификаторами по видам материала. Проверьте missing, поправьте вхождение через `material_figures` и `set_figure_layout`, снова запросите HTML.

## Выпустить исправленный листок

Считайте `lesson_state` и сохраните идентификатор действующей публикации.
Загрузите исправленный источник, проверьте сопоставление и HTML. В `publish_material`
передайте новую ревизию, режим publish, ожидаемые ID и версии действующей и запланированной публикаций.
Проверьте новую revisionId в истории и откройте опубликованную версию через `render_html`.

# Course in-person classes

`hasInPersonClasses` is live course metadata, default true. Disabling preserves enrollment attendance preferences, confirmed assignments, notification history and Staff historical reads. Student/Family hide all attendance badges, selectors and classroom information. Re-enabling restores stored preferences. Group changes remain available; mode changes are rejected while disabled.

Implementation: [migration](../../migrations/0103.course_in_person_classes.sql), [catalog API](../../apps/pwa_api/admin_course_routes.py), [enrollment domain](../../models/pwa/family_enrollment.py), [classroom reads](../../db_methods/pwa/classroom_assignments.py), [delivery](../../models/pwa/classroom_delivery.py), [notifications](../../models/pwa/notifications.py), [Staff editor](../apps/staff/src/course-catalog-editors.tsx), Student/Family home and enrollment pages.

Working assignment plans become stale on toggles. New event candidates, allocations, room notifications and classroom print scope require enabled courses. Pending deliveries recheck availability before execution; ordinary material PDFs remain available. Admin writes use existing course versions and audit events; omitted flags preserve values on edit.

Verification: isolated backend coverage includes migration up/down/up, existing defaults, admin rights/version/audit, legacy requests, preservation across toggles/group changes, mixed Student/Family scopes, pending Push/Telegram deliveries, print exclusions and historical reads. The Staff checkbox and both enrollment components pass UI tests; the real-runtime [browser scenario](../e2e/course-attendance.spec.ts) passed Chromium, Firefox and WebKit. Schema inventory, RU/EN catalogs and frontend type checks were updated.

Online operations use effective attendance while preserving the raw enrollment preference: [auth record](../../db_methods/pwa/auth.py), [oral roster](../../db_methods/pwa/oral_results.py), [news targeting](../../db_methods/pwa/news.py). Pending [layout confirmation](../../models/pwa/classroom_layouts.py) and [live room operations](../../models/pwa/live_marking.py) recheck the course in their write transaction. Staff reads retain historical room contexts.

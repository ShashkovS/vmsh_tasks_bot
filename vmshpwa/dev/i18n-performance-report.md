# i18n: отчёт о производительности

Бюджет и методика — [24-i18n.md](development-plan/24-i18n.md#производительность-бюджет-каждой-фазы). Baseline — чистый `7a9ddcbc` (до i18n), собранный и измеренный на той же машине подряд с рабочим деревом.

Инструменты:

- `node scripts/bundle-report.mjs` — brotli (quality 11, как на деплое) начального JS (entry + `modulepreload` из `index.html`), всего JS и каталогов;
- `node scripts/startup-benchmark.mjs` — медиана first-contentful-paint в Chromium, 9 прогонов, эмуляция сети 40 мс RTT / 12 Мбит/с, отдача brotli как у nginx, без API (замеряется загрузка бандла и каталога до стартового экрана);
- время `pnpm build` и `vitest run --project unit`, два прогона, среднее.

Прирост — runtime `@lingui/core` + `@lingui/react` и `@vmsh/i18n`. В P0 каталоги почти пусты; по мере перевода русские строки переезжают из route-чанков в каталог (в production в коде остаются только ID), поэтому общий объём для русского пользователя почти не меняется, а английский каталог загружается только при выборе английского.

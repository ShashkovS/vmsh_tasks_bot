# Интернационализация: русский → английский

Сквозной план, дополняющий фазы 1–11. Решение и мотивация — [ADR 0004](../../../adr/0004-pwa-internationalization.md); правила для разработчиков — [docs/i18n.md](../../docs/i18n.md); термины — [глоссарий](../../docs/i18n-glossary.md).

Подробная инструкция исполнителю на английском — [24-i18n-execution-plan.md](24-i18n-execution-plan.md): аудит состояния на `7fbbeb15`, поиск строк, границы UI/данных, примеры frontend/backend, каталоги, небольшие задачи P2–P8 по файлам и проверяемые критерии завершения.

## Уточнение состояния — 24 сентября 2026

P0–P4 реализованы локально; P5–P8 остаются в очереди. P4 перевела определённые в [i18n-scopes.json](../../i18n-scopes.json) Staff-поверхности проверки, live marking, результатов и статистики, не меняя сохранённые данные и протокольные значения. Полные phase-гейты в области P4, в том числе извлечение каталогов, прошли с pnpm 11.15.1; точные результаты приведены в пруфах ниже.

Проверка производительности P4 сравнивает рабочее дерево с P3 на той же машине: максимальный прирост initial JS — 7.9 KB, максимальная разница медианного cold FCP — 12 мс. Оба значения укладываются в бюджет. Исторические числа P0 всё ещё нужны как долгосрочная точка отсчёта; результаты последовательных сравнений — в [i18n-performance-report.md](../i18n-performance-report.md).

## Результат

Весь интерфейс Student, Family, Staff и Landing, серверные сообщения PWA API и Web Push доступны на английском. Язык выбирается в кабинете, хранится в аккаунте и по умолчанию русский. Каждая фаза выкатывается отдельно; английский виден всем с P1, непереведённые места показываются по-русски.

Вне объёма: Telegram-бот (включая сообщения, которые PWA отправляет через Telegram), контент уроков (условия, скомпилированные «Задача N / Ответ / Решение»), новости, названия курсов и групп, legacy-дашборды, форматы импорта XLSX/TSV и JSON legacy print, имя установленного приложения в manifest.

## Архитектура (кратко)

- Frontend: Lingui 6, русский текст в макросах служит ключом. Каталоги `src/locales/{ru,en}.po` у каждого пакета и приложения ([lingui.config.ts](../../lingui.config.ts)); приложение сливает их в `src/i18n/catalog-<locale>.ts`, по одному чанку на локаль.
- Сборка: [vite-i18n.ts](../../vite-i18n.ts) — компиляция `.po`, Babel-макросы только для файлов с макросами, preload русского каталога, guard «ID из кода есть в каталогах».
- Runtime: [`@vmsh/i18n`](../../packages/i18n/src/index.ts) — `bootstrapLocale` до первого рендера, `LocaleProvider` снаружи всех экранов, cookie устройства `vmsh-locale`, кешированные `Intl`-форматтеры.
- Backend: [helpers/pwa/i18n.py](../../../helpers/pwa/i18n.py) и [helpers/pwa/locales/en.po](../../../helpers/pwa/locales/en.po); `pwa_error_middleware` переводит `PwaApiError.message` на язык cookie.
- Области перевода: [i18n-scopes.json](../../i18n-scopes.json) — ESLint запрещает там неупакованную кириллицу, `make pwa-i18n-check` требует английский.

## Производительность (бюджет каждой фазы)

- Начальный JS (entry + modulepreload, brotli): не более +10 KB к baseline P0 на приложение.
- Каталог грузится параллельно с entry (preload), без последовательного запроса.
- Медиана FCP (cold и warm, `scripts/startup-benchmark.mjs`): не хуже baseline более чем на 30 мс.
- `pnpm build` и `pnpm test`: не более +25% к baseline P0.
- Горячие списки (live marking, очередь проверки, справочник) — без `<Trans>` в каждой ячейке; форматтеры только кешированные.

Замеры: `node scripts/bundle-report.mjs`, `node scripts/startup-benchmark.mjs`; отчёт — [i18n-performance-report.md](../i18n-performance-report.md).

### Рецепт фазы перевода (P1–P7)

1. Обернуть строки области в макросы; модульные карты — в `msg`; плюрализаторы — в ICU `plural`; `ru-RU`-форматтеры — в `useFormatters()`.
2. `make pwa-i18n-extract`, перевести новые `msgstr` (frontend `en.po`, backend `helpers/pwa/locales/en.po`) по глоссарию.
3. Добавить glob'ы области в `i18n-scopes.json` (frontend и backend).
4. Тесты затронутых компонентов — через `renderWithI18n` из `@vmsh/test-utils/i18n`; русские проверки остаются.
5. Расширить английский e2e smoke; просмотреть истории области в Storybook с глобалом «English».
6. DoD-гейты и `make pwa-i18n-check`; замеры по бюджету; пруфы ниже; записи в оба `STATUS.md`.

### P5–P8

Заполняются по мере выполнения по рецепту выше.

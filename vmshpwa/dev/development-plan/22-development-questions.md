# Вопросы, возникшие во время разработки

Здесь накапливаются только вопросы, без которых можно продолжать независимые
части разработки, но которые нужно решить до соответствующего production
cutover. После ответа решение переносится в основной план, а вопрос удаляется.

## Family-аккаунты

1. Каким способом администратор должен передавать родителю логин и первый
   пароль после создания Family-аккаунта: вручную через согласованный канал,
   письмом из Staff или другим способом? Нужен ли сразу после создания
   одноразовый экран, с которого эти данные можно скопировать, если позднее
   пароль больше нигде не показывается?

## Исторические письменные обсуждения

2. В `written_tasks_discussions` есть 40 531 сообщение занятий 1–37, для
   которого сохранились только Telegram `chat_id` и `tg_msg_id`: текста и
   локального файла нет, а `messages_log` пуст. Bot API не позволяет повторно
   получить произвольные старые сообщения по этим идентификаторам. Нужно ли
   показывать в общей хронологии на месте каждой такой строки нейтральную
   пометку «Историческое вложение недоступно», сохранив время, автора и исходные
   идентификаторы только в audit, или эти строки следует не показывать совсем?
   Если существует отдельный экспорт переписок или медиа за занятия 1–37,
   который можно использовать для восстановления, где он находится?

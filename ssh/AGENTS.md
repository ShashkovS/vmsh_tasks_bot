## Назначение

Каталог `ssh/` хранит локальный SSH-конфиг и ключи для доступа к серверу `vmshbeget`.

## Источник Истины

- `ssh/config` — канонический SSH-конфиг для алиаса `vmshbegetagent`.
- Корневой `AGENTS.md` — общая политика репозитория.

## Что Здесь Редактировать

- `ssh/config`, если меняются host alias, порт, пользователь или путь к ключу.
- Этот `AGENTS.md`, если меняется порядок подключения или модель доступа.

## Что Здесь Не Трогать

- Не коммитить новые приватные ключи без явной необходимости.
- Не менять alias `vmshbegetagent` без синхронного обновления документации, которая на него ссылается.
- Не использовать этот каталог для хранения произвольных server-side заметок.

## Команды Проверки

```bash
ssh -F ssh/config vmshbegetagent
ssh -F ssh/config -G vmshbegetagent
```

## Ограничения И Инварианты

- Подключение к серверу выполняется через `ssh -F ssh/config vmshbegetagent`.
- Ожидаемый пользователь на сервере — `vmshbegetagent`, у него нет `sudo`.
